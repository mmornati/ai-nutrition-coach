# Surface: public site — landing (website/index.html), docs (MkDocs under /docs/), videos (/video/)

Scope: the GitHub Pages site at mmornati.github.io/ai-nutrition-coach. Landing mode: Persuade; docs pages: Read; video player: Experience.
Audience: self-hosters deciding to run it, and the household cooks they install it for. Job: understand what it is, believe the trust story, run it, then learn every feature. Proof: real app screens, real commands, real outgoing requests, the trust table's named tests. No testimonials, metrics or press.

## Direction contract

THESIS: The site is the towel the app is made of, unfolded to page size: sections are woven bands, features are dyed stripes, absence is bare cotton. Refuses the split-hero-plus-feature-grid SaaS landing and the generic docs theme.

OWN-WORLD: DESIGN.md Torchon, inherited whole: White Cotton #FBFBF8 with 1px two-way weave, Torchon Ink #262421, four dyes only for food groups and always named, dashed seams for absence, Schibsted Grotesk only (900 tight names, 400 sentences, sentence case), 2px-ink pills, 4px sewn labels with inset dashed stitch, 8px cloth panels, flat (one shadow max).

STORY: In one viewport the visitor sees a day woven live and understands "honest plate, calm numbers, mine". Scrolling, each feature weaves its band; the trust band prints the real requests; they run one command or open the docs or the film.

FIRST VIEWPORT: Top bar (wordmark, rail-style pills, EN/FR note, Source on GitHub). Left 60%: a 3-line 900 headline (no kicker; the command lives in #run) "Know what's on your plate. Keep it yours." over a dashed seam, sub, ink pill "Run your own" + outline pill "Watch the 90-second tour". Bottom third: full-bleed day towel (Breakfast, Lunch, open Dinner) woven from the left on load. Right: the real Today phone, tilted, laid on the towel, with sewn trust labels.

FORM: Torchon, laid out — IMPECCABLE'S PICK, #1 on my grounded list; seed key a91577c7. Raises kept from the round: real outgoing requests printed in the trust band (from Phosphor); defaults drawn as line patterns, solid = on, gap = off (from Jackfield); planned work shown as its own honest layer (from Torn Billboard).

SIGNATURE INTERACTION: the towel weave — stripes slide in from the left edge one after another as a band enters view; reduced motion shows them at once.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
