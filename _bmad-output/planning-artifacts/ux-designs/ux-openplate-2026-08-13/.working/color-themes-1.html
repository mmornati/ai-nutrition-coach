OpenPlate · Color Themes 1 · 2026-08-13

Five ways to stay calm

A picker, not a redesign. Every register keeps the locked Calm Coach direction — no cards, one quiet accent, large type, hairline rules, the serif-italic coach whisper, tiny mono chips — only the skin changes. Light and dark are both in scope for each theme, because the evening kitchen and offline use are real OpenPlate moments.

each column = a register · lift hex from the token chips below, or from the comment block at the top of each theme's CSS
